# languages

Paquetes de idioma completos para **LaraJoom** (Joomla! basado en Laravel).

## Idiomas incluidos

| Idioma | Carpeta | Código |
|--------|---------|--------|
| Alemán | `de-DE-Full_language_LaraJoom` | de-DE |
| Francés | `fr-FR-Full_language_LaraJoom` | fr-FR |
| Italiano | `it-IT-Full-language-LaraJoom` | it-IT |
| Japonés | `ja-JP-Full-language-LaraJoom` | ja-JP |

## Estructura

Cada carpeta contiene un paquete de idioma completo con:
- `manifest.json` — manifiesto del paquete
- `administrator/language/{idioma}/` — archivos de traducción para el panel de administración
- `site/language/{idioma}/` — archivos de traducción para el sitio frontal (si aplica)

## Uso

Instalar los paquetes de idioma en LaraJoom a través del gestor de extensiones o copiando las carpetas al directorio de idiomas del proyecto.
